## ✨ Features

- **Click to reveal** — tap any question to expand the answer
- **Progress tracking** — green bar shows how many you've reviewed (saved in browser)
- **Search** — instantly find any concept, keyword, or topic across all tabs
- **Expand all** — open every answer at once for quick revision
- **Code blocks** — Python implementations with syntax highlighting
- **Dark theme** — easy on the eyes for long study sessions

## 🚀 Run Locally

**Option 1 — Just open in browser (simplest)**
```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/ml-interview-prep.git

# Open the file
cd ml-interview-prep
# Double-click index.html  OR:
open index.html        # Mac
start index.html       # Windows
```

**Option 2 — VS Code Live Server**
1. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension
2. Open `index.html` in VS Code
3. Click **"Go Live"** in the status bar
4. Opens at `http://127.0.0.1:5500`

No dependencies. No npm install. No build step. Pure HTML/CSS/JS.

## 📖 How to Use

1. **Pick a tab** from the sidebar based on what you want to study
2. **Click any question** to reveal the answer
3. **Search** for specific topics (e.g., "backpropagation", "LSTM", "KV cache")
4. Follow this study plan:

| Day | Focus |
|-----|-------|
| Day 1 | ML Fundamentals + Algorithms |
| Day 2 | Deep Learning + Transformer Deep Dive |
| Day 3 | LLM + NLP |
| Day 4 | System Design + MLOps |
| Day 5 | Statistics + Coding (run the code yourself!) |
| Day 6 | Full mock — go through all 220 questions in one sitting |
